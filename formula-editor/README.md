# 수식 편집기

`index.html` 하나로 동작하는 LaTeX 수식 편집기입니다. 브라우저로 파일을 열면 바로 쓸 수 있습니다. 수식 엔진(MathJax)과 ZIP 기능(JSZip)은 CDN에서 불러오므로 인터넷 연결이 필요합니다.

## 기능

- **수식 입력**: LaTeX 문법을 입력하면 바로 미리 보여 줍니다. 오류가 있으면 한국어로 알려 줍니다.
- **모든 수식 표현**: MathJax 전체 판(AMS, mathtools, physics, mhchem 화학식, cancel, color, braket 등)을 씁니다.
- **기호와 구조**: 구조, 그리스 문자, 연산, 관계, 화살표, 집합·논리, 괄호, 악센트, 함수, 큰 연산자, 행렬·배열, 글꼴, 기타·공백, 화학식 분류로 버튼을 모았습니다. 글자를 선택한 뒤 누르면 선택한 글자를 감쌉니다.
- **수식 예시 창**: 대수, 미분, 적분, 행렬, 확률·통계, 물리, 항공·드론, 화학 등 13개 분류에 100개가 넘는 예시가 있습니다. 검색할 수 있고, 예시를 바꿔 넣거나 커서 위치에 넣거나 보관함에 바로 추가할 수 있습니다.
- **글자 색상**: 기본 색 10가지, 색 고르기, 색상 코드 직접 입력.
- **PNG 저장 (투명 배경)**: 글자 크기, 여백, 해상도 배율(1×–4×)을 정할 수 있습니다. SVG 저장과 이미지 복사도 됩니다.
- **PNG 결과 미리보기**: 실제로 만들어질 PNG를 투명/흰/검은 배경에서 크기 정보와 함께 확인합니다.
- **결과 보관함**: 만든 수식을 모아 두고 골라서 쓸 수 있습니다. 선택한 항목을 개별 PNG로 저장, ZIP으로 묶어 저장, 한 장으로 합쳐 저장(세로/가로, 정렬, 간격), 현재 색상 일괄 적용, 편집기로 불러오기를 할 수 있습니다. 보관함은 브라우저에 저장됩니다.

## 단축키

- `Ctrl` + `Enter`: 보관함에 추가
- `Ctrl` + `S`: PNG 저장
