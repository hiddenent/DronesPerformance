# 2K·4K·8K 업스케일러

이미지를 넣으면 2K / 4K / 8K 해상도로 키워 주는 브라우저용 프로그램입니다. 설치할 것이 없고, 이미지는 내 컴퓨터 밖으로 나가지 않습니다.

## 사용법

1. `index.html`을 크롬·엣지·파이어폭스·사파리로 엽니다 (더블클릭).
2. 이미지를 끌어다 놓거나, 눌러서 고르거나, Ctrl+V로 붙여넣습니다.
3. 만들 해상도(2K, 4K, 8K)를 하나 이상 고릅니다.
4. **업스케일 시작**을 누르고, 결과 카드의 **저장** 버튼으로 파일을 받습니다.

결과 미리보기를 누르면 그 위치를 "단순 확대"와 나란히 1:1 픽셀로 비교해 볼 수 있습니다.

## 해상도 기준

| 이름 | 크기 | 화소 수 |
|---|---|---|
| 2K (QHD) | 2560 × 1440 | 3.7 MP |
| 4K (UHD) | 3840 × 2160 | 8.3 MP |
| 8K (UHD-2) | 7680 × 4320 | 33.2 MP |

- **16:9 화면 안에 맞춤** (기본): 원본 비율을 유지하면서 위 프레임 안에 꼭 맞게 키웁니다. 세로 사진은 9:16 프레임을 씁니다.
- **긴 변을 기준 길이에 맞춤**: 긴 변을 2560 / 3840 / 7680 픽셀로 맞춥니다.

## 처리 방식

- Lanczos3 보간(가로·세로 분리 처리)으로 계단 현상 없이 매끄럽게 키웁니다.
- **선명도 보정**은 업스케일 전에 원본 크기에서 언샵 마스크를 걸어, 확대 후에도 윤곽이 무르지 않게 합니다. 0%로 두면 끕니다.
- 투명 PNG는 알파를 고려해 처리하며, JPEG로 저장할 때는 투명 영역을 흰색으로 채웁니다.
- 계산은 웹 워커에서 돌기 때문에 처리 중에도 화면이 멈추지 않습니다.

## 한계

- 8K 한 장은 처리 중 1GB 안팎의 메모리를 씁니다. 휴대폰 브라우저(특히 iOS Safari)는 캔버스 크기 제한 때문에 8K 저장에 실패할 수 있으니 PC를 권장합니다.
- 보간 방식이므로 원본에 없던 디테일을 새로 만들어 내지는 않습니다. 그런 결과가 필요하면 Real-ESRGAN 같은 AI 업스케일 모델이 필요합니다.
