# 🌊 해양 날씨 예측기 (Gradio)

미래 날짜를 고르면 **최근 3년 동월(同月) 데이터의 평균 + 선형 회귀 추세선**으로
**수온·파고**를 빠르게 추정해 텍스트와 게이지 차트로 보여주는 경량 웹앱입니다.

```bash
pip install -r requirements.txt
python app.py          # http://127.0.0.1:7860
```

## 구성

| 파일 | 역할 |
|---|---|
| `marine_forecast.py` | API 호출(Open-Meteo Marine, 키 불필요) · 추정 알고리즘 · 사용자 친화적 예외 |
| `app.py` | Gradio UI — 날짜 선택(`gr.DateTime`), 해역 선택, 게이지/추세 차트, 요약 텍스트 |
| `tests/` | 가짜 API 응답으로 알고리즘·예외 처리를 검증 (`pytest`) |

## 알고리즘 (ML 모델 없음)

1. 목표 날짜와 **같은 월**이면서 이미 끝난 최근 3개 연도를 고릅니다.
   (예: 오늘 2026-11-05, 목표 2026-11-20 → 2023·2024·2025년 11월)
2. 연도별 호출을 **병렬**로 보내 시간별 수온·파고를 받고 일평균으로 집계합니다. (결과는 `lru_cache`로 캐시)
3. `예측값 = 연도 추세선(동월 평균 ~ 연도, np.polyfit)을 목표 연도로 외삽 + 월내 일별 기울기 × (목표일 − 월 중앙일)`
4. 잔차 표준편차를 `±` 예상 범위로 표시하고, 파고는 0 이상 등 물리적 범위로 클리핑합니다.

## 예외 처리

| 상황 | 사용자 메시지 |
|---|---|
| 지난 날짜 / 365일 초과 / 날짜 형식 오류 / 미선택 | "날짜를 다시 확인해 주세요" + 해결 방법 |
| 네트워크 오류·타임아웃·429·5xx·잘못된 응답 | "해양 데이터 서버에 연결하지 못했어요" + 재시도 안내 |
| 일부 연도만 실패 | 남은 연도로 추정하고 안내 문구 표시 |
| 육지·연안 좌표 등 과거 데이터가 비어 있음 | "참고할 과거 데이터가 없어요" + 먼바다 좌표 권장 |
| 1개 연도만 유효 | 추세 없이 평균으로 추정하고 안내 |

> ※ 과거 통계 기반의 기후학적 예상값이며 실제 기상 예보가 아닙니다.
