# 바다·날씨 예측 보기 (단일 HTML 웹앱)

한국 연안의 예측 기온·강수 확률·풍속·파고·수온을 신뢰구간과 함께 보여주는 단일 HTML 웹앱입니다.

| 파일 | 설명 |
|---|---|
| `forecast_app.html` | 웹앱 전체 (HTML·CSS·JS 한 파일, Chart.js만 jsDelivr CDN에서 로드) |
| `forecast_data.json` | 구조 확인용 **샘플** 데이터 (2개 지역 × 3일, 값은 모두 임의 예시) |

## 실행 방법

브라우저는 보안 정책상 `file://`로 연 페이지에서 `fetch()`로 로컬 JSON을 읽지 못합니다.
HTML 파일을 더블클릭해 열면 "데이터 없음" 안내가 나오므로, 간단한 로컬 서버를 띄워 여십시오.

1. 터미널에서 두 파일이 있는 폴더로 이동합니다.
2. 로컬 서버를 실행합니다. (Windows에서는 `python` 대신 `py`를 써야 할 수 있습니다.)

```bash
python -m http.server 8000
```

3. 브라우저에서 `http://localhost:8000/forecast_app.html` 에 접속합니다.
4. 종료할 때는 터미널에서 `Ctrl + C`를 누릅니다.

서버를 띄울 수 없는 경우, 화면의 **📂 JSON 파일 직접 열기** 버튼으로 `forecast_data.json`을 골라도 됩니다.
그래프(Chart.js)는 CDN에서 불러오므로 인터넷 연결이 필요합니다. 연결이 없어도 카드 결과는 표시됩니다.

## 데이터 파일 규칙 (`forecast_data.json`)

- 공공 API 키를 브라우저에 노출하지 않도록, API 호출과 가공은 서버·배치 스크립트에서 하고 결과만 이 JSON으로 저장합니다.
- `date`는 `YYYY-MM-DD` 형식입니다. 형식이 틀린 항목은 제외되고 화면에 제외 개수가 표시됩니다.
- 각 항목은 `{"mean", "low", "high"}` 객체입니다. `low`·`high`가 신뢰구간(하한·상한)입니다.
  - `rain_prob`는 숫자 하나(예: `30`) 또는 같은 객체 형태 모두 지원합니다.
- 값이 없거나 숫자가 아니면 해당 카드에 **데이터 없음**으로 표시합니다. 빈 값을 추정하거나 보간하지 않으며, 그래프 선도 그 날짜에서 끊깁니다.
- `meta` 선택 필드:
  - `units`: 항목별 단위 (없으면 ℃, %, m/s, m, ℃)
  - `interval_label`: 신뢰구간 이름 (예: `"80% 예측 범위"`)
  - `is_sample`: `true`이면 상단에 "샘플 데이터" 경고를 띄움. 실제 데이터에서는 빼거나 `false`로 설정
- JSON은 주석 문법이 없으므로 샘플 안내는 `_comment` 필드에 적었습니다. 앱은 이 필드를 무시합니다.

> 본 예측은 참고용이며 기상청 공식 예보를 대체하지 않습니다.
