# Circular Pixel 3D

이미지를 **원형 픽셀(Circular Pixel) 3D 입자**로 변환하고, 입력한 **스토리**를 입자
애니메이션 시퀀스로 재생하는 인터랙티브 3D 스토리텔링 그래픽 시스템입니다.

`index.html` **파일 하나**만 브라우저로 열면 바로 실행됩니다. (서버 불필요 · 외부 라이브러리 없음)

## 실행 방법

1. `index.html` 을 크롬 / 엣지 / 파이어폭스에서 연다 (더블클릭).
2. 업로드 전에도 **기본 예제 이미지**의 입자가 표시됩니다.
3. 왼쪽 `IMAGE` 패널에서 이미지를 선택하거나 드래그 앤 드롭합니다.

## 주요 기능

| 구분 | 내용 |
| --- | --- |
| 이미지 입력 | 파일 선택 · 드래그 앤 드롭 · JPG/PNG/WebP/GIF · 가로세로 비율 유지 |
| 원형 픽셀 변환 | 격자 중심점의 색을 추출해 원형 입자 생성, 간격 2~24px 조절(프리셋 2/5/10/15/20) |
| 3D 표현 | 입자별 X·Y·Z·RGB·크기·투명도·목표 위치, 밝기 기반 Depth/Height |
| 마우스 조작 | 드래그=회전, 휠=확대/축소, 우클릭(또는 Shift)드래그=이동, 더블클릭=초기화 |
| 터치 | 한 손가락=회전, 두 손가락=핀치 확대/축소 + 이동 |
| 스토리 | 한국어/영어 동작 키워드 14종을 인식해 Scene 시퀀스 자동 생성 |
| 애니메이션 | Linear / Ease In / Ease Out / Ease In Out / Cubic 보간, 속도 0.1~3배 |
| 타임라인 | Play · Pause · Stop · Restart · 스크럽 · 장면 클릭 이동 · 장면별 길이 조절 |

### 인식하는 스토리 키워드

모인다 · 흩어진다 · 해체된다 · 정렬한다 · 올라간다 · 내려간다 · 회전한다 ·
확대된다 · 축소된다 · 만들어진다 · 사라진다 · 나타난다 · 폭발한다 · 파도처럼 움직인다
(영어 keyword 도 함께 인식: gather, scatter, align, rise, fall, rotate, expand, shrink,
form, fade out, fade in, explode, wave)

"천천히 / 서서히" 가 들어간 문장은 1.5배 길게, "빠르게 / 갑자기" 는 0.65배 짧게 재생됩니다.

## 구현 메모

* **렌더링**: 외부 라이브러리 없이 순수 WebGL. 모든 입자를 `gl.POINTS` 한 번의
  draw call 로 그리고, 프래그먼트 셰이더에서 `gl_PointCoord` 로 원형 마스크와
  구체 음영을 적용합니다. DOM 요소는 하나도 생성하지 않습니다.
* **좌표계**: 이미지는 긴 변이 월드 100 단위가 되도록 배치됩니다(100 × 100 기준).
  분석 캔버스는 긴 변 500px 로 축소되며, `Pixel Spacing` 은 이 캔버스 기준 픽셀 값입니다
  (기본 10px → 50 × 50 격자).
* **성능**: 입자 데이터는 전부 TypedArray, 상한은 60,000개이고 초과하면 간격을
  자동으로 넓혀 샘플링합니다(HUD 에 "자동 샘플링" 표시). `requestAnimationFrame`
  기반 루프, 프레임당 위치/투명도 버퍼만 갱신합니다.
* **예외 처리**: WebGL 미지원, 컨텍스트 손실, 이미지 로드 실패, 캔버스 보안 제한
  상황에 각각 안내 메시지를 표시합니다.
